# Specs

1. Generacion de motores a partir de parametros basicos y visuales (sliders para cilindros, stroke, bore, etc)
2. Tener en cuenta motores exóticos como los rotativos.
3. Se debe tener en cuenta la geometría del exhaust, así como del intake.
4. El motor del juego debería ser compatible con todo (quizás Vulkan)
5. Escrito en Rust.
6. TDD
7. Exportacion de los motores a un json o yaml
8. Importacion de los motores a un json o yaml
9. Simulacion de carga, como caballos, par, marchas, etc para simular que corre el motor.
10. Vista en 3D del motor — al final del todo (pedido 2026-10-21).

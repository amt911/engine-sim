# 3D View — Phase 3 (layers: temperature, gas flow, combustion, cut-away) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The layers the user toggles over the 3D engine: the parts coloured by the temperatures
the simulation computes (with a legend), the gases flowing through the pipes, the combustion
glowing in each chamber, and a cut-away that opens the block and heads.

**Architecture:** Colours and streaks are per-instance data the UI writes each frame (no
per-frame meshes). The cut-away is a clip plane in the scene shader. Pipe gas states come from a
new engine-core read-only probe of the exhaust net, copied into the `Snapshot` at UI rate (a few
samples per pipe), so the sim thread does no extra work per step.

**Spec:** `docs/superpowers/specs/2026-11-03-3d-view-design.md` (phase 3). Starts after PR #89.

## Global Constraints

- Temperatures only where the simulation has one: cylinder gas (`CylinderView::temperature_k`),
  pipe gas (from each pipe's sound speed, T = c²/(γR)), exhaust pipe walls (`pipe_heat`, when
  `exhaust.gas_temperature` is on). Block, head, pistons: neutral, "no data" (physics first).
- The probe never runs per sim step: at most once per UI frame, O(pipes × 8 samples).
- Colour map: perceptually uniform and colour-blind safe (a fixed table, e.g. *inferno*, 300 K →
  1300 K), the legend drawn in egui over the view.
- Budget unchanged (CPU ≤ 2 ms p99, GPU ≤ 4 ms on the 5850U target); the bench gains a
  "all layers on" case.

## Review Focus

1. Exhaust net on its worker thread (`--threads`, the remote link) → the probe still reads a
   consistent block (or the last one), never a torn state. Task 2 test
   `the_probe_reads_the_same_with_the_net_elsewhere`.
2. Steepening / FV pipes (non-linear lines, finite volumes) → the probe reports for them too, or
   says it has no data; no panic. Task 2 test `every_exhaust_model_answers_the_probe`.
3. A pipe shorter than one sample spacing → one sample, not zero. Task 2.
4. Cut-away with the camera inside the clip plane → nothing vanishes but the cut half. Task 4.
5. Layers toggled while the engine is rebuilt → no stale per-pipe data mapped onto new pipes
   (states keyed by the definition version). Task 3.

---

### Task 1: Combustion and cylinder gas (app, pure)

- `scene::moving` adds a `Part::Charge` instance per cylinder: the gas between crown and deck
  (a cylinder of the bore), coloured by `temperature_k` through the colour map, emissive while
  `burning` (the shader takes a per-instance emission in the colour's alpha).
- Tests: the charge spans crown → deck (hand values at TDC and BDC); 300 K maps to the map's first
  entry, 1300 K to its last, clamped outside; `burning` sets the emission.

### Task 2: Exhaust gas probe (engine-core)

- `pub struct PipeState { pub temperature_k: f64, pub velocity_m_s: f64, pub pressure_pa: [f64; 8] }`
  and `ExhaustNet::probe(&self, out: &mut Vec<PipeState>)`, pipes in the order the 3D view lays
  them (primaries by cylinder, collectors by group, the after-collector chain, merge, tails);
  `Engine::probe_exhaust` reaches it through the remote slot (the last finished block).
  Temperature from the pipe's sound speed, velocity from its mean mass flow (ρ from p and T), the
  pressure as forward + backward waves at 8 points along it.
- Tests (hand values): a still pipe at 300 K reports c²/(γR) = 300 K and zero velocity; a forward
  pulse of 1 kPa in a 1 m pipe shows at the sample its travel time reaches; the probe allocates
  nothing once `out` has room; remote and in-place nets probe alike; every `ExhaustModel` answers.
- New public API: round-trip not needed (not serialised). Mutation run per the PR rule.

### Task 3: Temperature layer and legend (app)

- `Snapshot` carries `pipes: Vec<PipeState>` (taken at UI rate) and the definition version.
- Pipe instances recoloured from their pipe's gas temperature (walls from `pipe_heat` when on);
  parts without data drawn neutral; an egui legend (colour bar, 300–1300 K) in the view's corner;
  a **Layers** menu in the view bar: Temperature, Gas flow, Combustion, Cut-away.
- Tests: kittest toggles each layer and reads the state; the recolouring maps a hand-set
  `PipeState` to the expected colour.

### Task 4: Cut-away (app, shader)

- The scene shader discards fragments in front of a plane through the cylinders' axes (a uniform);
  with the layer on, the block and heads are drawn whole (not the back walls of phases 1–2) and
  the plane opens them.
- Tests: the plane from the definition (inline: z = 0; V: the bisector of each bank) by hand;
  off-screen renders with the layer on and off checked by eye.

### Task 5: Gas flow streaks (app)

- Short bright streaks (a stretched sphere instance each, ≤ 8 per pipe at High, 4 at Medium, 0 at
  Low) advance along each pipe's runs at its gas velocity (scaled ×0.05 to be seen, labelled in
  the legend), coloured by temperature; pulses (the probe's pressure samples) brighten them.
- Tests: a streak's position after Δt is v·scale·Δt along the runs (hand value); a reversed flow
  runs backwards; the count follows the detail level.

### Task 6: Bench, renders, gate

- Bench case with all layers on; renders of each layer; full local gate; PR with a manual test
  plan; verify-pr; merge; tag.

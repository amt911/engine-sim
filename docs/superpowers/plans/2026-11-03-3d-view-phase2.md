# 3D View — Phase 2 (intake, exhaust and turbo geometry) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw every engine's intake (air box, throttle, plenum, runners or individual throttle
trumpets), exhaust (primaries, collectors, the after-collector chain of pipes, catalysts,
silencers and resonators, the bank merge, the tails) and turbo (compressor, turbine, intercooler)
in the 3D view, with every pipe at its defined length and diameter.

**Architecture:** Pure modules turn the definition into still instances: a router lays a pipe of
given length as a compact polyline (straight runs + corners), and builders place the parts along
it. Straight runs are the existing unit cylinder; corners a new unit sphere; boxes the cuboid.
Built once per definition in `scene::build`, so nothing changes per frame and the renderer is
untouched except for the new sphere mesh.

**Tech Stack:** as phase 1 (Rust, glam, the phase-1 renderer).

**Spec:** `docs/superpowers/specs/2026-11-03-3d-view-design.md` (phase 2). Phase 1 plan:
`docs/superpowers/plans/2026-11-03-3d-view-phase1.md`. **Starts after PR #86 (phase 1) merges;
Task 4 (turbo) after PR #85 (turbo) merges**, both from `main`, no stacked PRs.

## Global Constraints

- Pipes are 1D in the sim: their 3D path is a layout choice, compact and readable, never claimed
  to be the car's routing. Each drawn pipe's path length equals its defined length (± 1 mm) and
  its radius is half its defined diameter.
- The scene is derived from the `EngineDef` only; meshes and still parts rebuilt only when it
  changes; no per-frame allocation.
- Performance budget unchanged (CPU ≤ 2 ms p99, GPU ≤ 4 ms at High on the 5850U target): the
  bench of phase 1 is rerun with the LFA V10 (most pipes) and must stay within it.
- Off-screen renders only.

## Review Focus

1. A pipe shorter than its bend allowance (e.g. a 5 cm tail) → drawn straight, never a negative
   or NaN segment. Pinned in Task 1 (`a_short_pipe_is_one_straight_run`).
2. An engine with no exhaust after the collector (`after_collector` empty, legacy muffler fields)
   or no plenum (ITBs) → still drawn, nothing missing. Pinned in Tasks 2 and 3.
3. Collector groups naming a cylinder twice or not at all (the editor's text field) → each
   cylinder's primary drawn once, to the group that lists it first, the rest to the last group.
   Pinned in Task 2 (`a_cylinder_left_out_of_the_groups_still_gets_its_primary`).
4. A rotary's exhaust (side/peripheral ports, no valves) → primaries start at the housing's port.
   Pinned in Task 2 (`a_rotarys_primaries_leave_its_housing`).
5. Very long tails (several metres) → folded inside a bounded box beside the engine, and the scene
   bounds grow to hold them (the camera still frames everything). Pinned in Task 1
   (`a_long_pipe_folds_inside_its_box`) and Task 5 (`bounds_cover_the_pipes`).

### Task 1: Router (pure)

**Files:** Create `crates/engine-app/src/view3d/routing.rs`.

**Interfaces:**
- Produces: `pub struct Run { pub from: Vec3, pub to: Vec3 }`;
  `pub fn route(start: Vec3, first_dir: Vec3, fold_dir: Vec3, lane: f32, length: f32, max_run: f32, out: &mut Vec<Run>) -> Vec3`
  — lays `length` metres from `start`: a first run along `first_dir` of `min(length, max_run)`,
  then back and forth on lanes `lane` apart along `fold_dir` (the caller passes 1.5 × the pipe's
  diameter), each run ≤ `max_run`; the legs between lanes count towards the length;
  returns the end point. The connecting legs between lanes count towards the length.
- [ ] **Step 1: Failing tests:** `the_runs_add_up_to_the_length` (lengths 0.3, 1.7, 4.25 with
  max_run 0.8, lane 0.06: Σ|to − from| = length ± 1e-4); `a_short_pipe_is_one_straight_run`
  (0.05 m → one run from start along first_dir, end = start + 0.05·first_dir);
  `a_long_pipe_folds_inside_its_box` (6 m, max_run 0.8: every point within 0.8 of start along
  first_dir and within ceil(6/0.8)·lane along fold_dir); `runs_are_continuous` (each run's `from`
  equals the previous `to`); zero or negative length → no runs, end = start.
- [ ] **Step 2:** Run → FAIL. **Step 3:** Implement. **Step 4:** Pass; sabotage the leg
  accounting (leave the connecting legs out of the length), see `the_runs_add_up…` fail, restore.
- [ ] **Step 5:** Commit `feat(app): lay a pipe of given length as compact runs`.

### Task 2: Exhaust geometry (pure)

**Files:** Create `crates/engine-app/src/view3d/ducts.rs` (exhaust part); modify
`view3d/mesh.rs` (`pub fn sphere(segments: u32) -> Mesh`, unit radius, smooth normals; tests:
every vertex at radius 1, normals = positions, indices in range), `view3d/scene.rs` (`Part::Pipe,
Part::Silencer, Part::Catalyst, Part::Resonator, Part::Turbo, Part::Intercooler, Part::Plenum,
Part::Airbox`, `MeshKind::Sphere`), `view3d/render.rs` (upload the sphere mesh).

**Interfaces:**
- Consumes: `route`, `scene::rod_between` (make `pub(crate)`), `EngineDef.exhaust`
  (`primary_length_m`, `primary_diameter_m`, `primary_length_deviation_m`, `collectors`,
  `collector_length_m`, `collector_diameter_m`, `collector_extra_length_m`, `after_collector:
  Vec<Segment>`, `merge: Option<Merge>`, `tail_length_m`, `tail_diameter_m`, `tail_outlets`,
  `tail_spacing_m`), the phase-1 head geometry (exhaust valve at +0.25 bore across the bore, deck
  height).
- Produces: `pub fn exhaust(def: &EngineDef, out: &mut Vec<Instance>)` — appends instances:
  each primary from its exhaust port (out of the head's exhaust side, then down), each collector
  from where its primaries meet, the after-collector chain in order (pipes as tubes; `Muffler` a
  cylinder of its `diameter_m` and `length_m` with its inner `tube_diameter_m` not drawn;
  `Catalyst` a cylinder in a distinct colour; `Resonator` a sphere of the neck's volume-equivalent
  size on a side branch; `Measured` a tube of its `bore_m`), the merge and its segments, then
  `tail_outlets` tails `tail_spacing_m` apart. Joint spheres at every corner with the pipe's
  radius. Colours: exhaust steel (0.55, 0.50, 0.47), catalyst darker, silencers lighter.
- [ ] **Step 1: Failing tests (hand values):**
  `each_primary_is_its_length_long` (inline4 preset: Σ run lengths of cylinder k's primary =
  `primary_length_m + deviation[k]`); `a_collector_starts_where_its_primaries_end`;
  `a_silencer_is_drawn_at_its_diameter` (a def with `after_collector = [Pipe 0.3 m Ø50 mm,
  Muffler 0.35 m Ø120.6 mm]` → a `Part::Silencer` instance whose x/z scale = 0.0603 and length
  0.35); `two_outlets_draw_two_tails_apart` (tail_outlets 2, spacing 0.1 → two `Pipe` runs whose
  ends are 0.1 m apart); `a_cylinder_left_out_of_the_groups_still_gets_its_primary`;
  `a_rotarys_primaries_leave_its_housing` (Renesis: first primary point within 1.1·(R+e) of the
  shaft); `legacy_muffler_fields_still_draw_a_tail` (after_collector empty).
- [ ] **Step 2:** Run → FAIL. **Step 3:** Implement. **Step 4:** Pass; sabotage the deviation
  (drop it), see `each_primary…` fail, restore.
- [ ] **Step 5:** Commit `feat(app): the exhaust in 3D at its defined lengths and diameters`.

# Turbocharger Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** an optional turbocharger on any engine definition: spool-up lag, boost limited by a
wastegate, an intercooler, a blow-off valve, the turbine damping the exhaust pulses.

**Architecture:** `crate::turbo` holds the cited 0D physics (compressor, turbine nozzle, shaft,
wastegate, intercooler) as pure functions plus a `Turbo` state stepped once per engine step. The
engine feeds it the exhaust's mean flow and temperature and reads back (a) the boost reservoir
the throttle draws from and (b) the turbine-inlet pressure the exhaust ports see as their mean
back pressure. Acoustically the turbine is a `Segment::Catalyst`-like restriction placed by the
preset (reuse, no new segment). No turbo: bit-identical.

**Tech Stack:** Rust, serde; no new crates.

**Spec:** `docs/superpowers/specs/2026-10-31-turbo-design.md`

## Global Constraints

- Physics cited in doc comments (Heywood 2nd ed. §6.8 eqs. 6.44/6.50/6.70; Dixon & Hall ch. 7);
  ESTIMATEs labelled. Expected test values by hand.
- `EngineDef::turbo: Option<TurboDef>`, serde default none, JSON+YAML round trip.
- Non-turbo presets bit-identical (existing preset hash tests unchanged).
- Heavy jobs: `taskset -c 0-5 nice -n19 scripts/heavy.sh … -j 6`.

## Rulings (my calls, from the code as it stands)

- **No diesel model exists yet**, so the spec's VW 1.9 TDI preset cannot be built here. The
  turbo is validated on a turbo petrol preset instead (Task 5); the TDI waits for the diesel
  combustion model. Cost if wrong: one preset swapped.
- **The FV intake's atmosphere is `ATM_PA` hard-coded** (`intake_fv.rs` boundaries): Task 2 adds
  an inlet state the engine sets each step; the 0D plenum path swaps `self.atm` for the boost
  reservoir.
- **Turbine acoustics:** the waveguide is linear about atmosphere; the turbine's mean pressure is
  a 0D offset on the ports' back pressure (filling-and-emptying, Heywood §7.6), its pulse damping
  an existing restriction segment in the preset's line.

## Review Focus

- Throttle snapped shut under boost: the BOV must vent, the shaft must not run away, no NaN.
- Engine stalled / cranking (zero exhaust flow): turbo at rest, boost 1 atm, no divide-by-zero.
- Wastegate set below ambient or zero turbine area in a file: clamp, never negative pressure.
- `Quality` presets with 2 substeps (dt changes mid-run): turbo state rebuilt or dt-independent.
- Old engine files: no `turbo` key → `None`, sound unchanged.

### Task 1: `crate::turbo` physics and `TurboDef`

**Files:** Create `crates/engine-core/src/turbo.rs`; modify `lib.rs`.

**Interfaces — Produces:**
- `pub struct TurboDef { compressor_tip_diameter_m, blades: u32, slip: f64, eta_c, eta_t, eta_m,
  turbine_area_m2, inertia_kgm2, wastegate_bar (gauge), intercooler_effectiveness,
  intercooler_drop_pa_per_kg2s2, bov: bool }` (serde default, deny_unknown_fields).
- `pub fn compressor_ratio(tip_speed: f64, eta_c: f64, slip: f64, t01: f64) -> f64`
- `pub fn compressor_power(m_dot: f64, t01: f64, ratio: f64, eta_c: f64) -> f64`
- `pub fn turbine_flow(area: f64, p03: f64, t03: f64, p4: f64) -> f64` (compressible nozzle)
- `pub fn turbine_power(m_dot: f64, t03: f64, p03: f64, p4: f64, eta_t: f64) -> f64`
- `pub struct Turbo` with `new(def, dt)`, `step(&mut self, exhaust_m_dot, t03, intake_m_dot,
  throttle_closing: bool) -> TurboState { boost_pa, boost_t_k, turbine_inlet_pa, shaft_rpm,
  bov_m_dot }`.

- [ ] Tests (hand values): ratio at U = 400 m/s, η 0.75, σ 0.9, 293 K → (1 + 0.75·0.9·160000/(1005·293))^3.5;
  compressor power at 0.1 kg/s ratio 2; turbine choked flow vs. Heywood C.8 nozzle; spool: from
  rest under constant 0.1 kg/s at 1100 K, 90 % speed after > 0.3 s; wastegate holds boost within
  5 % of its set point; zero flow → stays at rest; round trip JSON/YAML; old file without
  `turbo` → None.
- [ ] Run, see each fail; implement; pass; commit `feat(core): turbocharger physics (crate::turbo)`.

### Task 2: the intake breathes from the compressor

**Files:** `engine.rs` (throttle exchange), `intake_fv.rs` (inlet state setter).
- `IntakeNet::set_inlet(p_pa, t_k)`; engine uses `TurboState.boost_pa/boost_t_k` when turbo is
  some, `ATM_PA`/ambient otherwise (no turbo: bit-identical — the existing preset hash tests).
- [ ] Test: a 0D-intake engine held at 3000 rpm WOT with a fixed boost of 1.5 bar traps ≥ 1.4×
  the NA charge (ideal-gas density ratio 1.5·T_amb/T_boost). Commit.

### Task 3: the exhaust drives the turbine

**Files:** `engine.rs` (port back pressure), `turbo.rs`.
- Collector mean mass flow and temperature → `Turbo::step`; `turbine_inlet_pa − ATM_PA` added to
  the exhaust ports' downstream pressure.
- [ ] Tests: pumping loss rises with turbine inlet pressure (PMEP more negative); with turbo, a
  WOT step from 2000 rpm shows boost rising over > 0.3 s (lag). Commit.

### Task 4: wastegate, intercooler, blow-off valve noise

- BOV flow (throttle closing with boost > 0.2 bar) radiated by the existing jet noise model at the
  intake mouth; intercooler drop ∝ ṁ².
- [ ] Tests: lift-off from boost vents (BOV flow > 0, boost decays < 0.5 s), no NaN; a closed-
  throttle overrun without BOV leaves boost decaying through the throttle leak only. Commit.

### Task 5: a turbo petrol preset

- A published-spec turbo four (ESTIMATEs labelled), `presets/<name>.yaml`, the restriction for the
  turbine in its line. Dyno within 15 % of published power/torque; idle; spool lag audible.
- [ ] Dyno test; preset hash; clips (idle, drive, gears) sent to the user; FINDINGS/FACTS; PR with

# engine-sim — design spec (2026-10-21)

Status: **approved by delegation** — the user asked for autonomy ("te dejo hacer") and for an app
that is usable early, even if ugly, with progress tags for a timelapse. Sources:
[`docs/specs.md`](../../specs.md) and [`docs/research/simulador-motor-rust.md`](../../research/simulador-motor-rust.md).

## Goal

A desktop app (Rust, egui on wgpu → Vulkan/Metal/DX12/GL) where you:

1. Build an engine from basic parameters with sliders (cylinders, bore, stroke, rod, compression,
   layout inline/V/flat/rotary, firing order, cams, intake/exhaust geometry).
2. See it run: animated cross-section (pistons, rods, crank, valves; rotor for Wankel), gauges
   (RPM, torque, power, manifold pressure), plots (p–V, exhaust pressure, dyno curves).
3. Hear it: sound generated by the physics (exhaust pressure → DSP → speaker).
4. Load it: throttle, dyno, clutch, gears, vehicle mass/drag → it "runs".
5. Save/load engines as JSON or YAML.

## Architecture

Cargo workspace: `engine-core` (pure, deterministic physics + engine definition), `engine-audio`
(pure DSP + `cpal` sink), `engine-app` (eframe UI, sim thread, CLI, headless renderer). Three threads:
sim (fixed step, audio-rate multiple, writes `rtrb`), audio callback (pops only), UI (egui;
commands in via a channel, snapshots out via a shared latest-value slot). Audio buffer fill drives
the steps per block. Physics f64, audio f32, SI units inside.

Model ladder (from the research doc), each one replacing a part of the previous without changing
the outside contract (`Simulation::step(dt) -> sample`, `snapshot()`):

| Part | First version | Later |
| --- | --- | --- |
| Mechanics | analytic 1-DOF crank-slider, J(θ) | V banks, offsets, Wankel eccentric shaft |
| Gas | 0D volumes (intake, cylinder, exhaust runner, collector) + compressible orifice flow, γ const | γ(T) tables (NASA), 1D FV pipes (Rusanov → HLLC+MUSCL) |
| Combustion | Wiebe with spark advance, misfire, seeded cycle-to-cycle variation | turbulent entrainment |
| Heat / friction | Woschni-like simple loss, Chen–Flynn FMEP | per-component friction |
| Sound | exhaust-runner pressure + outflow derivative → DC block → low-pass → gain | waveguide exhaust, radiation filter, FFT convolution IR |
| Load | throttle + idle governor + dyno (speed hold) | clutch, gearbox, vehicle |

## Cases (what verification drives)

- Load each preset headless → WAV non-silent, finite, firing frequency = rpm/60 · cyl/2 (4-stroke).
- Throttle up → RPM rises; throttle closed → returns to idle; no NaN ever.
- Change cylinders slider → engine rebuilds, sound changes, no crash.
- Export YAML → import → identical engine.
- GUI opens and keeps running for several seconds.
